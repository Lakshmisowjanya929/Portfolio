# 🌸 Lakshmi Sowjanya — Personal Portfolio

A professional and responsive personal portfolio website built using **HTML, CSS, and JavaScript** to showcase my skills, education, internships, projects, certifications, and GitHub work.

## ✨ Features

- 🎨 Modern pastel-themed UI
- 📱 Fully responsive design
- 🏠 Professional hero section
- 👩‍💻 About Me section
- 🛠️ Technical skills section
- 💼 Internship experience
- 🚀 Projects showcase
- 🎓 Education details
- 📜 Certifications section
- 🐙 GitHub repositories integration
- 📩 Contact form
- 🌙 Light/Dark theme toggle
- ✨ Typing animation
- 🔍 Project filtering
- 🪟 Project details modal
- 📱 Mobile navigation menu
- 🎯 Scroll-based active navigation
- ⚡ Smooth animations and reveal effects
